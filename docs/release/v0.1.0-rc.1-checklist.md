## Ready 判定

只有以下条件全部满足时，Pull Request 才能转为 Ready：三个 RC job 均为 `PASS`；两个平台的 built-sidecar 和 packaged-app smoke 均为 `PASS`；三项下载产物的大小与 SHA-256 独立复核一致；安全与范围检查无失败；不存在未说明的阻断项。

任一 packaged-app smoke 为 `FAIL` 或 `NOT_RUN` 时，Pull Request 必须保持 Draft。hosted runner 的 GUI、挂载或安装限制应在“剩余阻断项”中写明，不能把源码验证或 bundle 静态检查转换成 packaged-app `PASS`。
