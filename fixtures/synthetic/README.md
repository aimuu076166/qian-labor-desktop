# 企安用工 Desktop Synthetic Fixtures

本目录只定义桌面版自动化验收的**完全虚构数据契约**。

## 原则

- 自动化测试与截图不得使用真实企业、真实员工或真实劳动材料。
- DOCX、PDF、图片等二进制测试材料优先在测试运行时生成，不把含个人信息形态的二进制样本长期提交到仓库。
- 运行时生成的材料必须显式标注“完全虚构”或使用 `QIAN_DEMO_20260824` synthetic marker。
- Fake Provider 可读取 `QIAN_SYNTHETIC_JSON=<json>` 作为确定性测试输入；该通道只用于测试和演示，不用于真实用户材料。
- 真实模型验收属于后续独立阶段，仍只能使用 synthetic 数据。

## 当前 foundation 垂直切片

测试运行时生成一个完全虚构 DOCX，包含：

- 虚构员工编号与姓名；
- 在职状态；
- 合同缺失事实；
- 已确认的身份归属；
- 低于系统管理参数的材料覆盖率。

目标是稳定验证：

`本地导入 → Fake Provider → 结构化事实 → R01–R20 → Dashboard → 风险来源 → 删除 → SQLite 重启后仍保持删除状态`。
